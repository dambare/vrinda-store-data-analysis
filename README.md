# Vrinda Store Data Analysis
Vrinda store wants to create an annual sales report for 2023. So that, Crinda understand their customers and grow more sales in 2024.



This Excel-based project provides data analysis and visualization for Vrinda Store's sales data. It helps in understanding revenue trends, top-selling products, and overall store performance.

## 📊 Features
- Clean and organized sales data
- Pivot tables for product/category analysis
- Charts & dashboards for quick insights
- Filters and slicers for interactive exploration

## 🚀 How to Use
1. Open the Excel file: `Vrinda Store Data Analysis.xlsx`
2. Navigate through the sheets:
   - Raw Data
   - Pivot Tables
   - Dashboard
3. Use slicers or filters to explore the data by category, date, etc.
